# 인기 글 대시보드 만드는 법 (PRD FR-07 · Looker Studio)

GA는 이벤트끼리의 비율(완독률 등)을 바로 계산하지 못해요. 그래서 무료 **Looker Studio**에 GA4를 연결하고, 글 ID별 표에 계산 필드를 만들어요. 연재님 구글 계정에서 한 번만 만들면, 그 뒤로는 월 1회 열어 보기만 하면 돼요.

## 0. 먼저 해 둘 것 (GA 맞춤 정의)

GA 관리 → 데이터 표시 → 맞춤 정의. 범위는 모두 **이벤트**.

| 종류 | 이름 | 매개변수 | 쓰는 곳 |
|---|---|---|---|
| 측정기준 | 글 ID · 글 제목 · 글 카테고리 · 읽은 정도 | `post_id` · `post_title` · `post_category` · `read_depth` | 이미 등록함 |
| 측정기준 | 글 발행일 | `post_published_at` | 게시 후 30일 필터 |
| 측정항목 | 머문 시간 (단위: 초) | `engaged_seconds` | 체류시간 지수 |

> 등록한 뒤 들어온 데이터부터 채워져요 (24~48시간).

## 1. 보고서 만들기

1. https://lookerstudio.google.com → **빈 보고서**
2. 데이터 추가 → **Google 애널리틱스** → 계정 `blog---261117` → 속성 (측정 ID `G-04G5123MB7`) → 추가
3. 차트 추가 → **표**
   - 측정기준: `글 ID`, `글 제목`, `글 카테고리`
   - 기간: 오른쪽 위 기간 선택에서 "지난 30일" (매달 바꿔 봄)

## 2. 계산 필드 만들기

데이터 소스 편집(연필) → **필드 추가** → 아래를 하나씩 붙여 넣어요. (이름은 왼쪽, 수식은 오른쪽)

| 필드 이름 | 수식 |
|---|---|
| 조회수 | `SUM(CASE WHEN 이벤트 이름 = "view_post" THEN 이벤트 수 ELSE 0 END)` |
| 완독 수 | `SUM(CASE WHEN 이벤트 이름 = "read_post" AND 읽은 정도 = "90" THEN 이벤트 수 ELSE 0 END)` |
| 반응 수 | `SUM(CASE WHEN 이벤트 이름 IN ("like_post", "bookmark_post", "share_post") THEN 이벤트 수 ELSE 0 END)` |
| 떠남 수 | `SUM(CASE WHEN 이벤트 이름 = "leave_post" THEN 이벤트 수 ELSE 0 END)` |
| 머문 시간 합 | `SUM(CASE WHEN 이벤트 이름 = "leave_post" THEN 머문 시간 ELSE 0 END)` |
| 완독률 | `완독 수 / 조회수` |
| 반응률 | `반응 수 / 조회수` |
| 평균 머문 시간 | `머문 시간 합 / 떠남 수` |

> 한글 화면이면 `이벤트 이름` · `이벤트 수`, 영어 화면이면 `Event name` · `Event count`로 적어요. 필드 이름은 데이터 소스 목록에 보이는 그대로 써야 해요.
> `unlike_post`(좋아요 취소)는 반응에서 빼지 않았어요. 누른 행동 자체를 반응으로 봐요. 빼고 싶으면 반응 수에서 `unlike_post` 수를 빼면 돼요.

### 체류시간 지수 (글 평균 ÷ 전체 평균)

표의 한 줄 안에서는 "전체 평균"을 바로 알 수 없어서 **매개변수**를 써요.

1. 리소스 → 매개변수 추가 → 이름 `전체 평균 머문 시간`, 숫자, 기본값 `60`
2. 표 위에 **스코어카드** 하나: 측정항목 = `평균 머문 시간` (측정기준 없음) → 이 숫자가 전체 평균
3. 매달 스코어카드 숫자를 매개변수 기본값에 넣어요
4. 필드 추가: `체류시간 지수` = `평균 머문 시간 / 전체 평균 머문 시간`

### 인기 점수 (PRD D3: 0.3 / 0.4 / 0.3)

| 필드 이름 | 수식 |
|---|---|
| 인기 점수 | `조회수 * (0.3 * 체류시간 지수 + 0.4 * 완독률 + 0.3 * 반응률)` |
| 표본 | `CASE WHEN 조회수 < 30 THEN "표본 부족" ELSE "" END` |

## 3. 표 완성

- 측정항목: 조회수 · 평균 머문 시간 · 체류시간 지수 · 완독률(%) · 반응률(%) · 인기 점수
- 측정기준에 `표본` 추가 → "표본 부족" 줄은 순위에서 빼고 봐요 (PRD: 조회수 30회 미만 제외)
- 정렬: 인기 점수 내림차순
- 컨트롤 추가 → **드롭다운**: `글 카테고리`
- 게시 후 30일 비교: 컨트롤 → 드롭다운 `글 발행일`로 같은 달 발행 글만 고르거나, 기간을 "발행일 ~ 발행일+30일"로 맞춰 봐요

## 4. 맞는지 확인 (PRD 인수조건)

1. 표의 글 하나를 골라요.
2. GA → 보고서 → 참여도 → 이벤트에서 같은 기간, `view_post`와 `read_post`(읽은 정도 90)의 이벤트 수를 그 글 ID로 걸러 봐요.
3. 완독 수 ÷ 조회수를 직접 계산한 값이 표의 완독률과 같으면 통과.

## 알아 둘 점

- GA 데이터는 24~48시간 늦게 들어와요. 실시간 순위가 아니에요.
- 광고 차단 방문자는 GA에 안 잡혀요. 좋아요 수의 정답은 Firestore(`postStats`) 숫자예요.
- 글별 조회수가 적은 초기에는 비율이 크게 흔들려요. 카테고리별로 먼저 보는 걸 추천해요.
- 댓글 기능은 없어서(2026-11-19 제거) PRD 반응률의 댓글 항목은 0으로 봐요.
