# PRD: AI 케이스 스터디 작성기 (Jae 블로그)

<sub>버전 v1.1 (이전 버전은 커밋 기록), 2026년 11월 24일 J 작성, 배포 https://blog---261117.web.app, 기준 화면 [프로토타입](../prototype.html)</sub>

## 1. 개요
방문객이 거의 없고 작업 과정이 보이지 않아 의뢰가 들어오지 않는 1인 디자이너 블로그에서, 운영자가 메모만 넣으면 AI가 케이스 스터디와 인스타그램 문구를 만들어 소상공인과 스타트업 마케터를 데려오고, 한 줄 의뢰로 바로 의뢰하게 한다.

## 2. 문제
**데스크리서치**: 디자인과 구현을 모두 하는 것이 강점, 빈 작업 섹션과 적은 방문자가 약점이다(SWOT). 고객은 내 문제를 어떻게 풀지 보고 고르고, 외주 플랫폼은 포트폴리오로 신뢰를 준다(3C).

**문제 발굴** (방문자가 오는 순서대로)
1. 블로그에 방문객이 거의 없다.
2. 방문자는 작업물과 과정을 볼 수 없어 믿고 맡기기 어렵다.
3. 방문자는 무엇을 어떻게 의뢰할지 몰라 의뢰서 쓰기가 막막하다.
4. 운영자는 작업을 케이스 스터디로 정리할 시간이 없다.
5. 운영자는 작업을 알릴 홍보 문구를 쓸 여유가 없다.

**문제 검증**: 의뢰자가 작업 과정을 보고 믿는지, 1인 프리랜서가 정리와 홍보 시간이 부족한지 공공 통계, 학술 논문, 공식 리포트 원문으로 확인한다. 결과: 검증 후 기입

**최종 정의**: 방문객이 거의 없고, 찾아온 방문자도 작업 과정을 볼 수 없어 의뢰하지 않으며, 운영자는 작업을 정리하고 알릴 시간이 없다.

## 3. 해결 방안
| 문제 | 해결 방안 |
|---|---|
| 1. 방문객이 거의 없다 | 게시할 때마다 인스타그램 문구를 만들어 사이트로 데려온다 (F7) |
| 2. 작업물과 과정을 볼 수 없다 | 작업 상세에서 요청, 과정, 결과를 보여 주고 의뢰 버튼을 둔다 (F3) |
| 3. 의뢰서 쓰기가 막막하다 | 한 줄만 적으면 비슷한 작업과 미리 채운 의뢰서를 보여 준다 (F1, F2) |
| 4. 정리할 시간이 없다 | 메모로 AI가 초안을 쓰고 운영자는 확인 후 게시한다 (F4, F5, F6) |
| 5. 홍보 문구를 쓸 여유가 없다 | 문구 3안 중 골라 복사만 한다 (F7) |

- **3.1 솔루션 정의**: 운영자는 메모만 남기고, 방문자는 과정을 보고 한 줄로 의뢰한다.

| 3.2 구분 | AS-IS | TO-BE |
|---|---|---|
| 컨셉 | 작업이 정리되지 않음 | AI가 정리, 사람이 확인 후 게시 |
| 타겟 | 적고 근거 없는 방문자, 바쁜 운영자 | 인스타그램으로 온 방문자, 시간을 아낀 운영자 |
| 비즈니스 모델과 가격 | 의뢰 수주 | 같음, 건당 AI 비용 100원 이하 |
| 기능 | 빈 작업 카드, 긴 의뢰 폼 | 작성기, 작업 상세, 한 줄 의뢰, 문구 |
| 디자인 | 이미지와 이름 카드 | 과정을 읽는 상세 (7장) |

- **3.3 예상 성과 (OKR)**: 방문자를 모아 의뢰를 시작하게 한다. KR1 25일까지 케이스 스터디 4건 게시, KR2 한 건 작성 10분 이내, KR3 4주 뒤 월 방문자 100명, 의뢰 버튼 클릭률 5%.

## 4. 가설 및 지표
| 가설 | 지표 | 목표 |
|---|---|---|
| H1 (문제 4) 작성 시간이 준다 | 메모 입력부터 게시까지 | 한 건 10분 이내 |
| H2 (문제 4) 초안을 믿을 수 있다 | 메모에 없는 사실, 고치지 않은 문단 | 0건, 60% 이상 |
| H3 (문제 2) 과정을 보면 맡기고 싶다 | 테스트 5명의 의뢰 의향(5점), 의뢰 버튼 클릭률 | 4명이 4점 이상, 5% |
| H4 (문제 3) 한 줄 의뢰가 쉽다 | 테스트 5명의 의뢰서 제출 시간 | 4명이 3분 이내 |
| H5 (문제 1, 5) 문구가 방문을 늘린다 | 인스타그램 공유 작업, 월 방문자 | 4건 모두, 100명 |

- **4.2 고객 정의**: 1순위는 포트폴리오로 디자이너를 고르는 소상공인과 스타트업 마케터다.
- **4.3 마케팅 메시지**: "결과물만이 아니라 문제를 푼 과정까지 보여드려요." 과장 없이 쓴다.

## 5. 기능적 요구사항
| 화면 | 기능 |
|---|---|
| 방문자 | F1 한 줄 의뢰, F2 의뢰서(레퍼런스 작업 고르기, 사진, 링크), F3 작업 목록과 상세(다른 프로젝트 보기) |
| 관리자 | F4 작업 입력(정보, 이미지, 메모 3칸), F5 AI 초안(보충할 점 안내), F6 미리보기와 게시(실패 시 직접 쓰기), F7 인스타그램 문구 3안(복사, 다른 문구) |
| 공통 | F8 GA4 이벤트(작업 조회, 의뢰 버튼, 의뢰 시작과 제출, 문구 복사) |

**유즈케이스**: 운영자는 메모, 초안 확인, 게시, 문구 복사 순서로 쓰고, 방문자는 인스타그램에서 와서 작업을 읽고 한 줄로 의뢰한다. **출시 이후**: 챗봇, 의뢰 AI 분석, AI 분야 추정, 자동 게시.

## 6. 비기능적 요구사항
- **동시 접속과 성능**: 방문자 동시 50명, 작업 상세 2.5초, AI 초안 1분 이내
- **보안**: API 키는 서버에만, 관리자 화면은 로그인, 메모는 관리자 전용, 게시는 확인 후
- **안정성**: AI가 실패해도 메모는 남고 직접 쓴다. 이름, 이메일, 사진은 제출 전 검사

## 7. 디자인 요구사항
- **방향**: 디자인 시스템, '초안 · 검토 필요' 표시, 360px, 버튼 44px, 대비 4.5:1, 다크 모드. [프로토타입](../prototype.html), [시안](https://claude.ai/artifact/4WLPHZ2fxuUN4uYXBvdAvE)
- **방문자 화면**: 홈은 "어떤 디자인이 필요하세요?" 한 줄 입력과 선택한 작업, 작업 상세는 커버, 요청, 과정, 결과, 의뢰 버튼, 다른 프로젝트 순서.
- **관리자 화면**: 작업 목록, 왼쪽 입력과 오른쪽 초안 미리보기, 게시 후 문구 화면.
