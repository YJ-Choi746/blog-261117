## 1. 문제 정의
> 방문자는 작업물과 작업 과정을 볼 수 없어 디자이너를 신뢰하지 못해 의뢰하지 않고, 1인 운영자는 작업이 끝나도 케이스 스터디로 정리할 시간이 없어 포트폴리오가 비어 있다.

- **현황(SWOT·3C)**: 작업은 있으나 작업 섹션이 플레이스홀더(W), 외주 플랫폼은 리뷰·포트폴리오로 신뢰를 줌(T), 의뢰자는 "내 문제를 어떻게 풀지"를 보고 고름(C), 케이스 스터디는 검색·SNS 콘텐츠로 재사용 가능(O)
- **문제 발굴과 우선순위(MoSCoW)**

| # | 문제 | 해결 방향 | 우선순위 |
|---|---|---|---|
| U1 | 방문자: 작업물·과정을 볼 수 없어 실력을 판단 못 함 | 케이스 스터디 게시 | Must |
| A1 | 운영자: 케이스 스터디로 정리할 시간이 없음 | AI 케이스 스터디 초안 | Must |
| A2 | 운영자: 홍보 SNS 문구를 쓸 여유가 없음 | AI SNS 문구 | Must |
| U2 | 방문자: 작성자에게 물어볼 곳이 없음 | 사이트 근거 기반 챗봇 | Should |

- **문제 검증 (데스크 리서치)**: ① 의뢰자는 포트폴리오·과정을 신뢰 근거로 삼는가 ② 1인 프리랜서는 정리 시간이 부족한가. **출처는 공공기관 통계·보고서, 학술지 논문(KCI·SCI), 발행처가 명시된 공식 리포트만** 쓰고(블로그·커뮤니티·AI 요약 제외), 원문을 직접 확인해 발행처·연도·URL·쪽 번호를 적는다.

## 2. 해결 방안
운영자가 **작업 이미지와 짧은 메모만 입력하면 AI가 케이스 스터디와 SNS 문구 초안**을 만들고, 운영자는 검토·게시만 한다. 방문자는 과정까지 보이는 작업 상세에서 바로 의뢰한다.

| 구분 | AS-IS | TO-BE |
|---|---|---|
| 운영자 | 정리 시간이 없어 사이트가 비어 있음 | 메모 → AI 초안 → 검토·게시 → SNS 공유 |
| 방문자 | 이미지·이름 카드뿐, 판단 근거 없음 | 커버 → 한 줄 요약 → 문제 → 과정 → 결과 → 의뢰 버튼 |
| 비즈니스 | 의뢰 수주가 수익원 | 동일, 운영비는 건당 LLM API 비용(측정 예정) |

- **OKR**: O. 방문자가 작업을 보고 신뢰해 의뢰를 시작한다 / KR1 출시까지 케이스 스터디 4건 이상, 플레이스홀더 0개 / KR2 1건 정리 시간 수동 대비 50% 이상 단축 / KR3 작업 상세 → 의뢰 시작 전환율, 출시 후 2주 기준선 측정
- **가설·지표**: H1 AI 초안이 정리 시간을 줄인다(건당 작성 시간, 50% 단축) · H2 초안은 믿고 쓸 만하다(메모에 없는 사실 0건, 수정 없이 쓴 문단 60% 이상) · H3 케이스 스터디가 의뢰로 이어진다(GA4 `case_view` → `case_cta_click` → `form_start` → `form_submit`) · H4(Should) 챗봇 근거 있는 답변 90% 이상(`chat_open`)
- **고객·마케팅**: 포트폴리오로 디자이너를 비교하는 소상공인·스타트업 마케터(의뢰자), 1인 디자이너(AI 사용자). 카피 "결과물만이 아니라 문제를 푼 과정까지 보여드려요", 성과 과장 금지, 생성 문구로 인스타그램·비핸스 공유

## 3. 요구사항

| ID | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 작업 입력 폼 (관리자) | 작업명·분야·업종·기간·이미지·메모(요청, 한 일, 결과) | Must |
| F2 | AI 케이스 스터디 생성 | 제목·한 줄 요약·문제/과정/결과·태그를 JSON으로 | Must |
| F3 | 편집·게시 | 초안 수정, 상태(초안/게시) | Must |
| F4 | 작업 목록·상세 (방문자) | 홈 '선택한 작업' 플레이스홀더 교체, 상세 페이지 | Must |
| F5 | 의뢰 연결 | 상세 하단 "이런 작업 의뢰하기", 의뢰 폼 분야 자동 선택 | Must |
| F6 | SNS 문구 생성 | 인스타그램·비핸스 문구와 해시태그, 복사 버튼 | Must |
| F7 | 실패 대체 경로 | AI 실패 시 빈 템플릿으로 직접 작성 | Must |
| F8 · F9 | GA4 이벤트 · 챗봇 | 게시 콘텐츠만 근거로 답, 없으면 의뢰 폼 안내 | Should |

- **유즈케이스**: 작업 입력(F1) → AI 초안(F2) → 검토·게시(F3) → SNS 문구 복사(F6) → 방문자 작업 상세(F4) → 의뢰 버튼(F5) → 의뢰 제출
- **범위 밖**: SNS 자동 게시, 이미지 생성·보정, 맞춤 추천, 의뢰서 점검
- **비기능**: AI 생성 20초 이내, 상세 로드 2.5초 이내(이미지 압축) · API 키는 서버에만, 관리자 기능 로그인 필수 · 메모에 없는 수치·성과 생성 금지, 게시는 운영자 승인 필수
- **디자인**: `docs/design-system.md` 유지, 관리자 화면은 입력(좌) / AI 초안 미리보기(우), 초안에 'AI 초안' 배지
