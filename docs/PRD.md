**개요**: 운영자가 이미지와 짧은 메모만 넣으면 **AI가 케이스 스터디와 SNS 문구 초안**을 만들어 비어 있는 포트폴리오를 채우고, 작업 페이지에서 바로 의뢰로 연결한다.

## 3. 문제
- **데스크리서치 (SWOT · 3C)**: SWOT 강점(S) 디자인과 구현을 모두 함 · 약점(W) 작업 섹션이 플레이스홀더 · 기회(O) 케이스 스터디는 검색·SNS 콘텐츠로 재사용 · 위협(T) 외주 플랫폼은 리뷰·포트폴리오로 신뢰를 줌 / 3C 고객(Customer) "내 문제를 어떻게 풀지"를 보고 디자이너를 고름 · 경쟁(Competitor) 외주 플랫폼 · 자사(Company) 작업은 있으나 정리 안 됨
- **문제 발굴**: U1 방문자는 작업물·과정을 볼 수 없음 / A1 운영자는 정리할 시간이 없음 / A2 홍보 문구를 쓸 여유가 없음 / U2 물어볼 곳이 없음
- **문제 검증 (데스크 리서치)**: ① 의뢰자는 포트폴리오·과정을 신뢰 근거로 삼는가 ② 1인 프리랜서는 정리 시간이 부족한가. 출처는 **공공기관 통계·학술지 논문(KCI·SCI)·발행처 명시 공식 리포트만**, 원문 확인 후 발행처·연도·URL 기재. 결과: [검증 후 기입]
- **최종 정의 (Must U1·A1·A2, Should U2)**: 방문자는 작업물과 과정을 볼 수 없어 디자이너를 신뢰하지 못해 의뢰하지 않고, 1인 운영자는 작업을 케이스 스터디로 정리할 시간이 없어 포트폴리오가 비어 있다.

## 4. 해결 방안
| 문제 | 세부 솔루션 → 해결 방식 |
|---|---|
| A1 정리 시간 없음 | AI 초안(F1~F3·F7) → 메모 3칸만 쓰면 AI가 작성(메모에 없는 숫자 경고, 실패 시 직접 작성), 운영자는 검토·게시 |
| U1 판단 근거 없음 | 작업 상세(F4) → 문제를 푼 과정까지 보여줌 |
| U1 의뢰로 안 이어짐 | 의뢰 연결(F5) → 상세 하단 의뢰 버튼, 분야 자동 선택 |
| A2 홍보 여유 없음 | SNS 문구(F6) → 문구·해시태그 생성, 복사만 |

**4.1 솔루션 정의**: 운영자가 작업 메모만 남기면 AI가 케이스 스터디와 홍보 문구를 만들어 포트폴리오를 채우고, 방문자는 문제를 푼 과정까지 보고 같은 화면에서 의뢰한다.

**4.2 AS-IS / TO-BE**
- **컨셉**: 작업은 있으나 사이트가 비어 있음 → 메모만 남기면 AI가 정리, 사람은 검토·게시
- **타겟**: 근거 없는 방문자·시간 없는 운영자 → 과정을 보고 신뢰하는 방문자·시간이 준 운영자
- **비즈니스 모델·가격**: 의뢰 수주가 수익원(유지), 기능은 무료 → 운영비는 건당 LLM 비용 ₩100 이하 목표(측정 후 확정)
- **기능**: 플레이스홀더 카드 → 작성기 · 작업 상세 + 의뢰 버튼 · SNS 문구 · (Should) 챗봇
- **디자인**: 이미지·이름 카드 → 상세는 읽는 순서 한 열 + 의뢰 버튼, 관리자는 입력(좌)·초안(우)

**4.3 예상 성과 (OKR)**: O. 작업을 보고 신뢰한 방문자의 의뢰 문의를 늘린다 · KR1 11/25까지 케이스 스터디 4건, 플레이스홀더 0개 · KR2 정리 시간 50% 단축 · KR3 출시 후 4주 작업 상세 → 의뢰 전환율·제출 수를 기준선(출시 전 2주) 대비 20% 증가

## 5. 가설 및 지표
| 가설 | 지표 | 목표 |
|---|---|---|
| H1 AI 초안이 정리 시간을 줄인다 (A1) | 건당 작성 시간 (수동 vs AI) | 50% 단축 |
| H2 AI 초안은 믿고 쓸 만하다 (A1) | 메모에 없는 사실 수 / 수정 없이 쓴 문단 비율 | 0건 / 60% |
| H3 케이스 스터디가 의뢰로 이어진다 (U1) | GA4 `case_view` → `case_cta_click` → `form_submit` | 기준선 +20% |
| H4 SNS 문구가 홍보를 쉽게 한다 (A2) | 게시 건 중 SNS 공유 비율 | 80% |

- **5.2 고객 정의**: **1순위** 의뢰자(포트폴리오로 디자이너를 비교하는 소상공인·스타트업 마케터) / 운영자(1인 디자이너, AI 사용자)
- **5.3 마케팅 메시지**: "결과물만이 아니라 문제를 푼 과정까지 보여드려요" · 용어 '작업'·'케이스 스터디'·'AI 초안' · 성과 과장 금지, 실명은 동의 시만
