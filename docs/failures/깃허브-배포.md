# 실패 로그 — GitHub 배포

## 2026-11-17 · Claude가 GitHub에 올리지 못함

**증상**
"깃헙에 배포해줘"라고 했는데 Claude가 저장소 목록을 불러오지도, 파일을 올리지도 못했어요.
- `gh auth status` → "The token in GH_TOKEN is invalid"
- 저장소 목록 도구 → "no GitHub account linked"

**원인**
Claude Code 클라우드 세션에 내 GitHub 계정이 연결돼 있지 않았어요.

**해결**
1. https://claude.ai/connect-github 에서 GitHub 계정을 연결하고 Claude GitHub App을 설치했어요.
2. 그 뒤 Claude가 저장소 목록에서 `YJ-Choi746/blog-261117`을 찾아 세션에 붙이고(쓰기 권한), `git clone` → `git commit` → `git push`로 올렸어요.
3. 로그인 정보는 세션의 git 프록시가 자동으로 붙여 줘서 토큰을 따로 입력하지 않았어요.

**배운 점**
클라우드 세션에서 GitHub 작업을 하려면 먼저 계정 연결이 필요해요. `gh` 명령어는 안 돼도 `git push`는 될 수 있어요.

## 2026-11-17 · 배포된 사이트가 열리는지 Claude가 확인하지 못함

**증상**
푸시는 성공했는데 Claude가 `https://yj-choi746.github.io/blog-261117/`에 접속하지 못했어요.
- `curl` → "CONNECT tunnel failed, response 403"
- 웹 가져오기 → "ENOTFOUND yj-choi746.github.io"
- GitHub Pages 설정 API → "Access to this GitHub API path is not permitted through this proxy"

**원인**
클라우드 세션의 네트워크 설정에서 `github.io` 주소와 Pages 설정 API가 허용돼 있지 않았어요.

**해결**
직접 브라우저로 주소를 열어 확인하기로 했어요. 404가 나오면 저장소 **Settings → Pages → Source: Deploy from a branch → gh-pages / (root) → Save**.

**배운 점**
Claude가 "올렸다"와 "사이트가 열린다"는 다른 단계예요. 배포 후에는 꼭 직접 주소를 열어 봐요.

## 2026-11-17 · 빈 저장소를 내려받을 때 경고

**증상**
`git clone` 결과가 "You appear to have cloned an empty repository"였어요.

**원인**
GitHub에서 저장소만 만들고 파일을 하나도 안 올린 상태였어요. 오류가 아니라 안내예요.

**해결**
그대로 파일을 추가하고 커밋한 뒤 `git push -u origin main`으로 첫 브랜치를 만들었어요.

## 2026-11-17 · Firebase Hosting 자동 배포가 실패 · "Run workflow" 버튼을 못 찾음

**증상**
- `main`에 올리자 "Deploy to Firebase Hosting"이 자동 실행됐지만 **실패**했어요 (배포 단계에서).
- Actions 탭에서 "Run workflow" 버튼이 보이지 않았어요.

**원인**
- GitHub Secret `FIREBASE_SERVICE_ACCOUNT`(서비스 계정 키)를 아직 넣지 않아서 Firebase에 로그인할 수 없었어요.
- "Run workflow" 버튼은 Actions 탭 **왼쪽 목록에서 워크플로 이름을 눌러야** 오른쪽 위에 나와요. 휴대폰 GitHub 앱에서는 보이지 않을 수 있어요.

**해결**
- 키를 넣은 뒤, 실패한 실행 화면의 **Re-run all jobs**를 누르거나, Claude에게 말하면 빈 커밋을 올려 다시 실행해요.
- **결과 (같은 날)**: 키를 넣은 뒤 다시 올리자 "Deploy to Firebase Hosting"이 **성공**했어요 (실행 44028103477). 이제 `main`에 올릴 때마다 `blog---261117.web.app`에도 자동으로 올라가요.
