# 실패 로그 — 캔버스 레이아웃

## 2026-11-17 · 푸터 아래 흰 여백이 들쭉날쭉함

**증상**
- 첫 화면에서 푸터 아래 흰 공간을 없애려고 푸터에 `height: 5px`를 직접 넣었더니, 푸터 글자가 상자 밖으로 넘쳐 위치가 어색했어요.
- 글 목록 · 글 상세 화면은 푸터 아래 흰 공간이 첫 화면보다 훨씬 컸어요.

**원인**
- 캔버스의 화면 틀(프레임) 높이가 실제 내용보다 길게 잡혀 있었어요. 남는 높이가 그대로 흰 공간으로 보였어요.
- 고정 `height`는 내용보다 작으면 글자가 넘쳐요.

**해결**
1. 고정 높이를 지우고, 페이지 루트를 `display: flex; flex-direction: column`, 푸터를 `flex: 1 0 auto; min-height: 72px; display: flex; align-items: center`로 바꿨어요. 남는 흰 공간을 푸터가 채우고, © 글자는 그 가운데에 와요.
2. 루트가 flex가 되면서 `max-width` + `margin: 0 auto` 섹션이 좁아지지 않게 `width: 100%; box-sizing: border-box`를 붙였어요.
3. 글 목록 · 글 상세는 브라우저로 내용 높이를 재서 프레임 높이를 맞췄어요 (2200 → 2016px, 2900 → 2501px).

**배운 점**
여백을 줄이려면 상자 높이를 억지로 줄이지 말고, 프레임 크기를 내용에 맞추거나 남는 공간을 채우는 배치(flex)를 써요.

## 2026-11-17 · 휴대폰에서 서비스 칸 중 "브랜딩"만 왼쪽으로 치우침

**증상**
휴대폰 첫 화면에서 브랜딩 · UI/UX 디자인 · 콘텐츠 제작 세 칸이 위아래로 쌓일 때, 브랜딩만 왼쪽에 붙어 보였어요.

**원인**
세 칸은 넓은 화면(3칸 나란히) 기준으로 여백이 달랐어요. 첫 칸은 왼쪽 여백 0, 나머지 두 칸은 왼쪽 여백 32px + 세로선. 화면이 좁아져 한 줄씩 쌓이면 이 차이가 그대로 보였어요.

**해결**
900px 이하에서는 1열로 바꾸고 세 칸 모두 같은 여백(위아래 32px, 좌우 0), 칸 사이는 가로선. 360 · 390 · 768px에서 세 제목의 왼쪽 끝이 같은 것을 테스트로 확인.

**배운 점**
"첫 칸만 다르게" 준 여백은 화면이 좁아져 배치가 바뀌면 티가 나요. 반응형에서는 배치가 바뀌는 지점에서 여백도 같이 다시 정해요.
