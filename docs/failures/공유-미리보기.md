# 공유 미리보기 (카카오톡 · SNS)

## 2026-11-17 · 글 주소는 미리보기가 뜨는데 홈 주소는 안 뜸
- **증상**: `p/글ID.html` 공유 주소는 카카오톡에서 제목 · 요약 · 썸네일 카드가 뜨는데, 홈(`index.html`) 주소는 카드가 뜨지 않음.
- **원인**: 미리보기는 페이지의 og 태그(`og:title` · `og:description` · `og:image`)를 읽어서 만드는데, og 태그를 글 공유 페이지에만 넣고 홈 · 글 목록에는 넣지 않았음. 홈에는 대표 이미지도 없었음.
- **해결**: 홈 · 글 목록 `<head>`에 og 태그를 넣고, 미리보기 이미지 `images/og-home.png`(1200×630)를 만들어 Firebase 주소로 연결.
- **참고**: 카카오톡은 한 번 읽은 미리보기를 한동안 저장해 둬요. 고친 뒤에도 예전 모습이 보이면 카카오 개발자 사이트의 공유 디버거(developers.kakao.com → 도구 → 공유 디버거)에서 주소를 넣고 "캐시 초기화"를 누르거나, 주소 뒤에 `?v=2`를 붙여 보내 보세요.
