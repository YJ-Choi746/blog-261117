# 공유 미리보기 (카카오톡 · SNS)

## 2026-11-17 · 글 주소는 미리보기가 뜨는데 홈 주소는 안 뜸
- **증상**: `p/글ID.html` 공유 주소는 카카오톡에서 제목 · 요약 · 썸네일 카드가 뜨는데, 홈(`index.html`) 주소는 카드가 뜨지 않음.
- **원인**: 미리보기는 페이지의 og 태그(`og:title` · `og:description` · `og:image`)를 읽어서 만드는데, og 태그를 글 공유 페이지에만 넣고 홈 · 글 목록에는 넣지 않았음. 홈에는 대표 이미지도 없었음.
- **해결**: 홈 · 글 목록 `<head>`에 og 태그를 넣고, 미리보기 이미지 `images/og-home.png`(1200×630)를 만들어 Firebase 주소로 연결.
- **참고**: 카카오톡은 한 번 읽은 미리보기를 한동안 저장해 둬요. 고친 뒤에도 예전 모습이 보이면 카카오 개발자 사이트의 공유 디버거(developers.kakao.com → 도구 → 공유 디버거)에서 주소를 넣고 "캐시 초기화"를 누르거나, 주소 뒤에 `?v=2`를 붙여 보내 보세요.

## 2026-11-17 · 카카오톡은 썸네일이 뜨는데 Slack은 안 뜸
- **증상**: 같은 공유 주소(`p/글ID.html`)가 카카오톡에서는 썸네일까지 뜨는데 Slack에서는 썸네일이 안 보임.
- **원인(가장 유력)**: 공유 페이지에 사람을 글로 보내는 `<meta http-equiv="refresh">`와 `<link rel="canonical">`(post.html)을 넣어 뒀음. 카카오톡은 이걸 따라가지 않지만, Slack 미리보기 봇은 따라가는 것으로 알려져 있어서 `post.html`의 기본 정보(대표 이미지 없음)를 읽은 것으로 봄. 세션에서 Slack에 직접 붙여 보지는 못해서 확정은 아님.
- **해결**: 공유 페이지에서 meta refresh · canonical을 빼고 스크립트로만 넘어가게 함(미리보기 봇은 스크립트를 실행하지 않음). `og:image:width/height` · `og:image:secure_url` · `twitter:image`도 추가. 대표 이미지가 없는 글은 `images/og-home.png`를 기본 썸네일로. `post.html`에도 기본 og:image를 넣음.
- **참고**: Slack도 미리보기를 한동안 저장해 둬요. 예전 모습이 보이면 주소 뒤에 `?v=2`를 붙여 다시 보내 보세요.
