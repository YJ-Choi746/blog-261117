# 실패 로그 — 의뢰 폼 이메일

## 2026-11-17 · 받을 이메일 주소가 전달되지 않음

**증상**
선택지 창에서 "다른 주소 입력"을 골랐는데, 정작 주소는 Claude에게 전달되지 않았어요. 폼의 받는 주소가 `RECEIVER_EMAIL`인 채로 남아서 의뢰를 보내도 메일이 올 수 없는 상태였어요.

**원인**
선택지에서 "Other"를 고르고 칸에 직접 적어야 하는데, 선택지 이름만 고르고 넘어갔어요.

**해결**
채팅으로 이메일 주소를 다시 알려줬고, Claude가 폼의 `action`에 넣어 다시 배포했어요.

**배운 점**
선택지 창에서 직접 입력이 필요한 항목은 텍스트 칸에 꼭 적어요. 안 되면 채팅으로 보내요.

---

## 확인해야 할 것 (아직 남은 일)

- **처음 한 번은 활성화가 필요해요.** FormSubmit은 첫 의뢰가 들어오면 받는 메일함으로 활성화 메일을 보내요. 버튼을 눌러야 그다음 의뢰부터 메일이 와요. 스팸함도 확인해요.
- **이메일 주소가 페이지 코드에 보여요.** 스팸이 올 수 있어요. 활성화 후 FormSubmit이 주는 무작위 코드로 `action` 주소를 바꾸면 가릴 수 있어요.
