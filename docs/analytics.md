# 방문자 통계 (Google Analytics 4)

블로그에는 GA4가 연결돼 있어요. 측정 ID는 `G-04G5123MB7`이에요. Firebase 프로젝트 `blog---261117`에 연결된 GA4 속성이에요.
GA 화면: https://analytics.google.com → 속성 이름 `blog---261117` (Firebase 콘솔 → 왼쪽 메뉴 **Analytics**로 들어가도 같은 곳이에요)

## 무엇을 모으나

| 페이지 | 모으는 것 |
|---|---|
| 첫 화면 `index.html` | 방문(page_view) |
| 글 목록 `posts.html` | 방문(page_view) |
| 글 상세 `post.html?id=…` | 방문(page_view, **글 제목이 페이지 제목**) + `view_post` 이벤트 (글 id · 제목 · 카테고리) |
| 의뢰 완료 `thanks.html` | 방문 + `generate_lead` 이벤트 (의뢰가 들어온 횟수) |
| 관리자 화면 `admin/…` | **모으지 않아요** |

지역 · 기기 · OS · 브라우저 · 화면 크기 · 유입 경로(검색, SNS 등)는 GA가 자동으로 모아요.

## 보고 싶은 것 → GA에서 보는 곳

| 보고 싶은 것 | GA 메뉴 |
|---|---|
| **지금 들어와 있는 사람** | 보고서 → **실시간** |
| **홈 화면 방문자 수** | 보고서 → 참여도 → **페이지 및 화면** → 표에서 페이지 제목 "Jae — 웹·앱 디자인 & 콘텐츠" 줄의 **사용자** 숫자 |
| **페이지별 방문자 수** | 보고서 → 참여도 → **페이지 및 화면** (조회수 · 사용자 · 평균 참여 시간) |
| **가장 많이 읽은 글** | 같은 표에서 제목이 "글 제목 — Jae"인 줄들을 조회수로 정렬 (글 상세는 글 제목으로 기록돼요) |
| **지역** | 보고서 → 사용자 → 사용자 속성 → **인구통계 세부정보** (국가 · 도시) |
| **기기 · OS · 브라우저** | 보고서 → 사용자 → 기술 → **기술 세부정보** (기기 카테고리 · 운영체제 · 브라우저) |
| **어디서 들어왔나** | 보고서 → 획득 → **트래픽 획득** |
| **의뢰가 몇 번 들어왔나** | 보고서 → 참여도 → **이벤트** → `generate_lead` |

> 처음 연결하면 보고서에 숫자가 나오기까지 **24~48시간** 걸려요. **실시간**은 바로 보여요.

## 더 자세히 보고 싶을 때 (선택, 한 번만)
`view_post` 이벤트의 글 제목 · 카테고리로 표를 만들려면 "맞춤 측정기준"을 등록해야 해요.
1. GA → 관리(톱니바퀴) → 데이터 표시 → **맞춤 정의** → **맞춤 측정기준 만들기**
2. 아래 3개를 하나씩 만들어요 (범위: **이벤트**)
   - 측정기준 이름 `글 제목` · 이벤트 매개변수 `post_title`
   - 측정기준 이름 `글 카테고리` · 이벤트 매개변수 `post_category`
   - 측정기준 이름 `글 ID` · 이벤트 매개변수 `post_id`
3. 그 뒤 보고서 → 참여도 → 이벤트 → `view_post`에서 글 제목 · 카테고리별로 볼 수 있어요 (등록한 다음부터 쌓여요).

## 내 방문 빼기 (설정 완료 · 자동)
**관리자로 로그인한 적 있는 브라우저는 GA로 아무것도 보내지 않아요.** 집 · 카페 · 휴대폰 어디서든, 그 브라우저에서 한 번만 로그인하면 돼요. IP 등록은 하지 않았어요 (IP는 장소마다 바뀌어서 금방 새요).
- 다른 기기(휴대폰 등)도 빼려면: 그 기기 브라우저에서 관리자 로그인을 한 번 해요. 로그인하지 않고 빼려면 사이트 주소 끝에 `?ga=off`를 붙여 한 번 열어요. 예: `https://blog---261117.web.app/?ga=off`
- 내 방문도 다시 집계하려면: 주소 끝에 `?ga=on`을 붙여 한 번 열어요.
- 브라우저 기록(사이트 데이터)을 지우면 표시도 지워져요. 그때는 다시 로그인하거나 `?ga=off`.
- 그래서 내 브라우저로는 GA **실시간**에 내가 안 잡혀요. 연결이 잘 됐는지 보려면 다른 브라우저(시크릿 창 등)로 사이트를 열어 보세요.

## 코드
- `js/analytics.js`: GA를 불러오는 파일. 방문자용 페이지 4개(`index`, `posts`, `post`, `thanks`)의 `<head>`에 들어 있어요. `/admin/` 주소와, 관리자 표시(`localStorage`의 `jae-ga-optout`)가 있는 브라우저에서는 아무것도 하지 않아요.
- `js/firebase.js`의 `markAdminBrowser()`: 로그인 · 글쓰기 · 글 관리 화면에서 관리자가 확인되면 표시를 남겨요.
- 글 상세는 `<html data-ga-defer>`로 자동 기록을 끄고, `js/post.js`가 글 제목을 불러온 뒤 한 번 기록해요.
