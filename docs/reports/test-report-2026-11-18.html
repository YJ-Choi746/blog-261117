2. 테스트 방법

화면 · GA 이벤트

  • 로컬 서버 + 실제 크롬(Playwright)으로 글 상세 · 글 목록 · 관리자 화면을 열어 확인
  • Firebase는 가짜 모듈로 바꿔 끼움 (실제 데이터 건드리지 않음)
  • 시계를 빨리 감아 5초 · 30초 · 60초 같은 시간 조건 확인
  • GA로 가는 값은 dataLayer를 읽어 확인
  • 휴대폰 폭 360px에서 가로 넘침 · 버튼 높이 44px 측정

보안 규칙

  • Firestore 에뮬레이터(구글 공식, 실제 규칙 엔진)에 firestore.rules를 그대로 올려 검사
  • 방문자 · 다른 로그인 계정 · 관리자 3가지 신분으로 허용 / 거부를 하나씩 확인
  • 개발자 도구로 직접 보내는 요청(값 조작 · 칸 추가 · 시간 조작)도 포함
  • 실제 서비스 규칙은 사용자가 콘솔에 게시 (2026-11-18)

결론 — 완료 기준 40개 중 35개 통과, 실패 0개. 남은 5개는 실제 GA 수신처럼 배포 · GA 등록 뒤에만 확인할 수 있는 항목이에요. US-10 위젯은 받은 패치의 테스트 결과에 보안 점검(위험 코드 제거 · 360px)을 더했어요. 9개 항목 중 7개가 실제 사이트에 배포됐어요 (GitHub Actions: Firebase Hosting · GitHub Pages 성공). 실제 GA 수집과 실서비스 동작은 배포 후 확인 항목으로 3쪽에 정리했어요.

6. 한계

  • 좋아요 · 저장은 로그인이 없어 브라우저를 바꾸면 다시 누를 수 있고, 저장은 다른 기기와 동기화되지 않아요 (PRD 허용).
